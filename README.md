# cuddly-couscous
###### ai真牛逼
#### 🚀 快速开始

1. **环境准备**：
    - 安装 Python 3.x。
    - 安装依赖库：`pip install selenium pillow`
    - 确保本地已安装 Chrome 浏览器，并配置好对应的 ChromeDriver（或使用 webdriver-manager 自动管理）。
2. **运行代码**：
    - 将代码保存为 `crawler.py`。
    - 在终端执行：`python crawler.py`。
3. **操作流程**：
    - 启动后，根据终端提示输入数字选择参数（如运行模式、是否等待登录等）。
    - 若选择“等待登录”，请在弹出的浏览器中完成登录操作，然后回到终端按回车键继续。
    - 爬取结束后，所有文件将自动保存至指定的输出目录。

#### ⚙️ 参数说明

| 参数选项 | 说明 |
| ------ |------ |
| **目标 URL** | 可使用默认的华为云课程链接，或输入自定义网址。 |
| **运行模式** | **正常模式**：可见浏览器窗口；**无头模式**：无界面后台运行。 |
| **等待登录** | **是**：手动登录网页后按回车继续；**否**：自动运行。 |
| **保存内容** | **全部内容**：HTML+截图+图片+Canvas；**仅 Canvas**：只保存画布内容。 |
| **输出目录** | 指定文件保存的文件夹名称（默认为 `output`）。 |
